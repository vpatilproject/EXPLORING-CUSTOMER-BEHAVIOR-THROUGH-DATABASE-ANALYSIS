# Exploring Customer Behavior Through Database Analysis

## Project Overview
This project analyzes customer purchasing behavior using SQL and an Online Food Delivery database.

The analysis focuses on sales, customers, products, Gold membership users, purchase patterns, and customer activity.

## Problem Statement
The objective is to understand customer behavior and purchasing patterns using database analysis and SQL queries.

## Objectives
- Analyze total sales revenue
- Identify top-selling products
- Analyze Gold membership users
- Compare Gold and non-Gold customer behavior
- Find customer purchase frequency
- Identify most purchased products
- Analyze customer spending patterns
- Study purchases before and after Gold membership

## Database Tables
The project uses the following tables:

- Sales
- Product
- User_name
- Users
- Goldusers_Signup

## SQL Analysis
The project contains 20 SQL queries covering:

1. Total sales revenue per product
2. Top 3 products by sales revenue
3. Number of Gold membership users
4. Revenue from Gold users
5. Total Gold-user revenue
6. Gold membership duration
7. Most popular product among Gold users
8. Total sales revenue by year
9. Revenue change over years
10. Average Gold signup compared with regular signup
11. Orders by Gold members
12. Total amount spent by each customer
13. Customer visit frequency
14. First order by each customer
15. Most purchased item
16. Most popular item for each customer
17. First item purchased after Gold signup
18. Item purchased before Gold signup
19. Orders and amount spent before Gold signup
20. Transaction ranking for Gold users

## Methodology
1. Database tables were created and populated with project data.
2. SQL queries were written to analyze customer and sales behavior.
3. Aggregate functions, joins, subqueries, GROUP BY, ORDER BY, CASE statements and window functions were used.
4. The results were analyzed to identify customer and product-level insights.

## SQL Concepts Used
- SELECT

- JOIN

- Window Functions
- Ranking

## Key Insights
- Sales data can be used to identify high-performing products.
- Customer spending and purchase frequency help identify valuable customers.
- Gold membership data can be used to compare member and non-member behavior.
- Purchase history helps understand customer preferences and repeat purchasing patterns.

## Recommendations
- Focus on high-performing products.
- Identify and retain high-value customers.
- Use Gold membership to improve customer loyalty.
- Provide personalized offers based on customer purchase history.
- Encourage repeat purchases through targeted promotions.

## Project Limitation
The available project data does not provide complete readable Gold membership records for all analysis cases. Therefore, some Gold membership-related results may be NULL or zero depending on the available data.

## Conclusion
This project demonstrates how SQL can be used to explore customer behavior, sales performance, purchasing patterns, and membership activity from an online food delivery database.
